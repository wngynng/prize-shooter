# 夜市神枪手 · Prize Shooter

气枪打奖品休闲游戏原型（Web Canvas，**50 关 · 十章架构**，**全章默认开放**——Ch3~10 章专属机制随版本逐步落地）。支持桌面 + 手机，**横屏版**（画面为 960×540 横版场景，双侧按键布局）。

## 在线试玩（GitHub Pages）

**<https://wngynng.github.io/prize-shooter/>** —— 手机/电脑浏览器打开即玩，无需安装（建议手机横屏；国内网络如打不开，需自备代理访问 `*.github.io`）。

## 运行

- **桌面开发版**：浏览器直接打开 `index.html`（无需构建/服务器）。
- **手机版单文件**：`dist/夜市神枪手-手机版.html`（约 117KB，零外部依赖）——
  微信/QQ/网盘发送到手机，用浏览器打开即玩；也可上传任意静态托管。
- 存档保存在 localStorage（v2 格式）；旧版 v1 存档首次启动自动迁移（原档保留）；清除浏览器数据即重置，大厅右下角也有「重置」。
  注意：同一浏览器里 file:// 页面共用一份存档（开发版与单文件版进度互通）。

## 重新打包

修改源码后运行 `powershell -File build-mobile.ps1`，即重新生成 `dist/夜市神枪手-手机版.html`。

## 操作

**桌面**：鼠标移动瞄准 · 左键射击 · 空格点按屏息（时停）· 双侧按钮同样可点

**手机（横屏，最佳体验）**：
- 布局：顶栏（弹药/命中/风向/**屏息条**/退出）→ 横版摊位画面 + **画布两侧独立按键列**（不遮挡画面）
- **滑动屏幕任意位置**即可移动准星（相对拖动：准星只随拖动位移移动，**无需点住准星再拖**；多指防劫持：瞄准手指已登记时忽略后落手指——按开火/开镜时擦过画布不会夺走瞄准）
- 左侧 🫁 **屏息**（点按=进入时停，再点退出）+ 🔫 **开火**（点按开火，长按连发）；右侧 🔭 **开镜**（点按切换 **2× 狙击镜**——CS2 式椭圆镜片 + 十字分划线**恒居镜片正中**，拖动灵敏度减半利于精瞄）+ 🔫 **副开火**（与主开火同逻辑）
- **屏息 = 时停（极慢）**：点按后世界陷入 20 倍慢镜——吊摆/传送带/坠落/粒子近乎冻结；**子弹不受影响照常飞行、命中即时反馈**（打中的奖品碎屑还会慢镜漂浮）；再点退出或耐力条耗尽**自动退出**并**调息 5s**（红色斜纹 = 锁定不可用，回满自动解锁）
- 竖屏窗口时画面自动旋转铺满并提示「转动手机到横屏」
- 触屏首次点击自动尝试**全屏+锁定横屏**（浏览器不允许无手势强制系统方向，这是最接近的方案；Android 生效，iOS 无锁屏 API 靠旋转显示兜底）
- 大厅「⛶ 全屏」按钮可随时切换沉浸模式

屏息让准星稳定（慢镜中漂移近乎静止），持续 2.5s。初始金币 1000。

`landscape-backup/` 为 v0.1 最初桌面横屏版的源码备份（现版本已原生横屏+双侧按键，此备份仅作历史记录）。

## 玩法与数值

设计文档：[DESIGN.md](./DESIGN.md)（数值表 ×8 + 功能模块清单 + 经济平衡模型）· 扩展蓝图：[王玉宁-50关扩展设计方案.md](./王玉宁-50关扩展设计方案.md)（50 关逐关数值总表）

一句话：打中什么拿什么。奖品在展馆查看图鉴，随时可卖金币——图鉴永久保留展出记录。
每天 1 次免费入场；破产可领**动态救济金**（随进度增长、领后必能入场），永远玩得下去。

**关卡架构（50 关 · 十章）**：每章 1 个创新机制，章内 5 关按「教学 → 应用 → 变体 → 验收」节奏递进；通关验收关解锁下一章。大厅为**两级导航**：章牌网格（进度/锁定/敬请期待三态）→ 章内关卡卡（最佳命中/清台记录）。

- **第 1 章 · 夜市入门**（弹道三要素）：无风静止 → 微风 → 下坠 → 吊摆 → 三要素叠加验收
- **第 2 章 · 铁轨夜市**（移动靶预判）：慢速传送带 → **对开双带**（上下反向）→ **转盘环形靶**（切线预判）→ 快带 → 吊摆+双带+转盘三重叠加验收
- **第 3~10 章**（✅ 已开放可玩 · 章机制逐步落地）：天气 / 弹种掩体 / 目标行为 / 限时连击 / 纵深高抛 / 幽灵镜像 / Boss 战 / 终局试炼——关卡当前以基础弹道+摆/带/盘运动可玩，章专属机制表现随 M2~M5 补齐（数值已锁定不改）
